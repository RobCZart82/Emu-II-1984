# Contributing

Start with docs/ROADMAP.md and docs/BUILD.md. Keep emulation core independent
of plugin/UI frameworks. Add tests for observable hardware or parser behavior,
including malformed inputs and boundary cases. State uncertainty explicitly.

Own contributions use AGPL-3.0-only. Record upstream provenance and licensing
before importing dependencies. Do not commit original firmware, operating
systems, factory banks, samples or private files. Use synthetic fixtures.

Submit a pull request with milestone, source audit and validation evidence.
Review is required before merging development changes into main.
